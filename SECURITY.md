# Sicurezza

Non inserire credenziali reali nel repository. Configurare il database tramite
variabili d'ambiente (`DB_HOST`, `DB_USER`, `DB_PASS`, `DB_NAME`) o tramite il
segreto del provider di hosting.

Per segnalare una vulnerabilità, contattare il maintainer del repository senza
pubblicare dettagli sfruttabili in una issue pubblica.
